# 🥊 Mashka Box Training Club — Landing Page con Bootstrap 5

Sitio web responsivo del gimnasio **Mashka Box Training Club**

---

## 📋 Descripción del proyecto

Landing page completamente responsiva para el gimnasio Mashka Box Training Club, ubicado en Latacunga, Ecuador. El sitio presenta información sobre los planes de membresía, horarios, beneficios, galería de imágenes y formulario de inscripción. El diseño fue migrado de CSS puro a **Bootstrap 5**, aplicando un flujo de trabajo colaborativo con **Git y GitHub**.

## 🛠️ Tecnologías utilizadas

- **HTML5** — Estructura semántica del sitio
- **Bootstrap 5.3.3** — Framework CSS para diseño responsivo y componentes UI
- **JavaScript** (Bootstrap Bundle) — Interactividad del navbar, carrusel y componentes dinámicos
- **Git** — Control de versiones local
- **GitHub** — Repositorio remoto y colaboración en equipo

## 🚀 Cómo ejecutar el proyecto

1. Clona el repositorio:
   ```bash
   git clone https://github.com/JosDEV10/gym_bootstrap.git
   ```
2. Ingresa a la carpeta del proyecto:
   ```bash
   cd gym_bootstrap
   ```
3. Abre `index.html` en tu navegador preferido.

> No requiere servidor ni instalaciones adicionales. Bootstrap se carga desde CDN.

## ✅ Componentes Bootstrap utilizados

- `navbar` + `navbar-toggler` — Menú responsivo con hamburguesa
- `carousel` — Galería de imágenes automática
- `card` — Tarjetas de planes de suscripción
- `table` + `table-responsive` — Tabla comparativa de planes
- `form-control` — Formulario de inscripción
- `btn` — Botones de acción
- `container` / `row` / `col` — Sistema de grillas responsivo
- `ratio ratio-16x9` — Mapa embebido responsivo
